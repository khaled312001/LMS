How The Web Actually Works — Step by Step

When a user types https://swissbridgeacademy.com and presses Enter, here is what happens in the ~200 milliseconds before the page appears.

  1. 1DNS lookup — the browser asks a DNS server for the IP address of swissbridgeacademy.com.
  2. 2TCP handshake — the browser opens a connection to that IP address on port 443.
  3. 3TLS handshake — the server presents its certificate and both sides agree on encryption keys.
  4. 4HTTP request — the browser sends GET / HTTP/2 along with cookies and headers.
  5. 5Server routing — Laravel / Node / PHP matches the request to a controller and executes business logic.
  6. 6Database query — the controller asks MySQL for the home-page data.
  7. 7HTTP response — the server streams back HTML (or JSON), the browser parses and renders it.

When To Use Which AI

  • ▶Learning a new concept → ChatGPT or Claude (ask them to explain like you're 12)
  • ▶Writing a first draft of code → Cursor Composer or GitHub Copilot
  • ▶Reviewing a pull request → Claude (upload the diff and ask for feedback)
  • ▶Debugging a mysterious error → Paste the stack trace + surrounding code into Claude
  • ▶Architecting a new feature → ChatGPT to brainstorm, Cursor to implement
  • ▶Writing tests → Cursor or Copilot (they love deterministic tasks)
  • ▶Generating documentation → any of them — all are excellent at docs

The "AI as Junior Teammate" Mindset

“Treat AI the way you would treat a smart but inexperienced junior engineer. Give them context, review their output, never merge their code blindly.”— Core principle of this bootcamp

This mindset protects you from the two most common failure modes:

❌

Blind Trust

Copy-pasting AI code without reading it. Leads to hallucinated APIs, security holes, and subtle bugs.

❌

Blind Distrust

Refusing to use AI out of pride. Leads to being 10x slower than your peers.

Anatomy of a Great AI Prompt

A great prompt has four components: Role, Context, Task, Format (R-C-T-F).

prompt
ROLE:
  You are a senior Laravel developer with 10 years of e-commerce experience.

CONTEXT:
  I am building an online store that sells Swiss watches.
  The project uses Laravel 11, MySQL 8, and Blade templates.
  Orders table currently has: id, user_id, total, status.

TASK:
  Add a shipping_address_id column + migration + Eloquent relation.
  Validate that the address belongs to the same user.

FORMAT:
  Return the migration file, the updated Order model,
  and 3 PHPUnit tests covering happy path + 2 edge cases.
RememberSpecificity beats eloquence. Numbers, names, and examples always help.

Hands-On: Your First AI-Assisted Code Session

Open ChatGPT or Claude in a new tab and paste this prompt:

prompt
You are a senior frontend engineer.

Write a single HTML file that displays a 'Hello, World!' message
centered on the page with:
  - A gradient purple-to-pink background
  - White text, font-size 48px, modern sans-serif font
  - A subtle fade-in animation on page load

Return only the file contents, no explanation.

Save what it returns as hello.html, open it in a browser. Congratulations — you just built your first AI-assisted web page.

Ethics & Responsibility of AI-Assisted Coding

Never do thisNever paste customer data, API keys, or passwords into a public AI tool. Use the enterprise or offline versions for sensitive code.
Always do thisRead every line of AI-generated code. Run it locally. Understand what it does before it hits production.
Best practiceMaintain a local .ai-context.md file in each project so the AI always has the right background.
