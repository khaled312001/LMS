Installing Node.js 22 (LTS)

Node.js runs JavaScript outside the browser and powers npm, React tooling, and Express servers.

bash
# Windows: use the official installer from nodejs.org

# macOS / Linux — use nvm (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 22
nvm use 22

# Verify
node --version   # → v22.x.x
npm --version    # → 10.x.x
Why nvm?Different projects need different Node versions. nvm lets you switch in one command.

Installing PHP 8.3 & Composer

bash
# Windows: download from windows.php.net, add to PATH
# macOS:
brew install php@8.3 composer

# Ubuntu:
sudo apt install software-properties-common
sudo add-apt-repository ppa:ondrej/php -y
sudo apt install php8.3 php8.3-cli php8.3-mysql php8.3-xml php8.3-mbstring

# Install composer globally
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Verify
php --version           # → PHP 8.3.x
composer --version      # → Composer version 2.x

Installing MySQL 8

  1. 1Download MySQL Community Server 8.x from dev.mysql.com
  2. 2During install, set a strong root password and SAVE it in your password manager
  3. 3Install MySQL Workbench for a GUI (optional but recommended)
  4. 4Confirm installation: mysql --version
  5. 5Start the server: mysqld --initialize --console
Password ruleNever reuse passwords between local and production. NEVER commit them.

Creating Your First AI-Ready Project

bash
mkdir my-first-ai-project && cd my-first-ai-project

# Initialise Git
git init

# Create an AI context file
cat > .ai-context.md << 'EOF'
# Project: My First AI Project
## Stack
- Node 22, TypeScript, React 19
- TailwindCSS 4
- Vitest for tests

## Conventions
- Use functional React components with hooks
- Tailwind only, no styled-components
- All files must pass \`pnpm lint\` before commit
EOF

# .gitignore
cat > .gitignore << 'EOF'
node_modules/
.env
.env.local
dist/
.DS_Store
EOF

code .
Power moveA .ai-context.md file at the root of every project primes Cursor/Copilot with your conventions.

Environment Variables 101

Never hard-code secrets. Always load them from .env.

ini
.env   (never commit this file)
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=super-secret
OPENAI_API_KEY=sk-...

.env.example   (commit this so teammates know the keys)
DB_HOST=
DB_USER=
DB_PASSWORD=
OPENAI_API_KEY=

Installing & Using Postman (or Thunder Client)

You need a tool to hit your APIs before wiring up a UI. Thunder Client lives inside VS Code and is free.

  1. 1Open Thunder Client from the VS Code sidebar
  2. 2Click "New Request"
  3. 3Method = GET, URL = https://jsonplaceholder.typicode.com/users
  4. 4Hit Send — observe the JSON response
  5. 5Try POST with a JSON body in the next practice
