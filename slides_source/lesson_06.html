Specificity — Who Wins?

When two rules target the same element, the more specific selector wins. Think of specificity as a four-digit number:

SelectorSpecificityExample
Inline style1,0,0,0style="color:red"
#id0,1,0,0#main
.class, [attr], :pseudo0,0,1,0.card
tag, ::pseudo-element0,0,0,1p, ::before
!importantOverrides everything. Use only as a last resort.

The Box Model

css
/* Every element is a box with four boundaries */
.card {
  box-sizing: border-box;  /* include padding+border in width */
  width: 320px;
  padding: 16px;
  border: 2px solid #6366f1;
  margin: 12px;
}

/* Universal rule — put this at the top of every stylesheet */
*, *::before, *::after { box-sizing: border-box; }

Flexbox — 1D Layout

css
.nav {
  display: flex;
  justify-content: space-between;  /* main-axis  */
  align-items: center;             /* cross-axis */
  gap: 1rem;
  padding: 1rem 2rem;
}

.nav-links {
  display: flex;
  gap: 1.5rem;
  list-style: none;
}

/* Responsive: stack vertically on mobile */
@media (max-width: 640px) {
  .nav { flex-direction: column; }
}
Mental modelFlex thinks in rows (or columns). For full 2D layouts use Grid.

CSS Grid — 2D Layout

css
.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  min-height: 100vh;
  gap: 1rem;
}
header  { grid-area: header;  }
nav     { grid-area: sidebar; }
main    { grid-area: main;    }
footer  { grid-area: footer;  }
Cheat codegrid-template-areas makes layouts readable like ASCII art.

Responsive Product Grid In 6 Lines

css
.products {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 1.5rem;
}

That one rule creates a responsive grid that grows from 1 to N columns automatically, without media queries.

Media Queries — The Mobile-First Way

css
/* Base = mobile */
.card { font-size: 1rem; padding: 1rem; }

/* 640px+ */
@media (min-width: 40rem) {
  .card { font-size: 1.125rem; padding: 1.5rem; }
}

/* 1024px+ */
@media (min-width: 64rem) {
  .card { font-size: 1.25rem; padding: 2rem; }
}
Why mobile-first70%+ of traffic is mobile. Write for phones first, enhance for desktops.

Container Queries (2024+)

css
.product-card {
  container-type: inline-size;
  container-name: card;
}

@container card (min-width: 400px) {
  .product-card { display: grid; grid-template-columns: 120px 1fr; }
}

Container queries style an element based on its own size, not the viewport — essential for reusable components.

Custom Properties (CSS Variables)

css

  --primary:   #6366f1;
  --secondary: #ec4899;

}
.button {
  background: var(--primary);
  border-radius: var(--radius);
  box-shadow: var(--shadow-md);
}
/* Dark-mode override */
@media (prefers-color-scheme: dark) {

Transitions — Smooth Interactions

css
.button {
  background: #6366f1;
  transform: translateY(0);
  transition: background 200ms ease,
              transform  200ms ease;
}
.button:hover {
  background: #4f46e5;
  transform: translateY(-2px);
}
RuleTransition only transform and opacity — they are GPU-accelerated and won't jank.

@keyframes Animations

css
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0);   }
}
.hero-text { animation: fadeUp 700ms 100ms ease-out both; }

/* Respect user\'s motion preference */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}

Modern Color — OKLCH

css
:root {
  /* Perceptually uniform — consistent brightness */
  --brand-500: oklch(60% 0.2 270);
  --brand-600: oklch(52% 0.22 270);
  --brand-700: oklch(44% 0.22 270);
}

.button {
  background: var(--brand-500);
  color: oklch(98% 0.02 270);
}

OKLCH replaces HSL. It lets you build perceptually even color ramps from a single hue.

Performance Tips

  • ▶Avoid @import in CSS (extra request); use <link>
  • ▶Minify and tree-shake in production
  • ▶Use will-change: transform only for animating elements — then remove it
  • ▶Audit with Lighthouse — keep "Unused CSS" under 10%
  • ▶Self-host fonts with font-display: swap
