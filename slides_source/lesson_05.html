The Anatomy of an HTML5 Document

html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Swiss Bridge Academy</title>
  <meta name="description" content="AI-powered full-stack bootcamp">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header><!-- nav --></header>
  <main>
    <article>
      <h1>Welcome</h1>
      <p>Content goes here…</p>
    </article>
  </main>
  <footer>© 2026</footer>
  <script src="app.js" defer></script>
</body>
</html>

Semantic Tags — Why They Matter

TagUse for
<header>Top bar, logo + nav
<nav>Primary navigation
<main>The unique page content (only one per page)
<article>A standalone piece (blog post, product card)
<section>A thematic grouping with a heading
<aside>Related but tangential (sidebar)
<footer>Page or section footer
<figure>/<figcaption>Image with a caption

Forms — The Complete Toolkit

html

Accessibility — Quick Wins

  • ▶Every <img> has an alt attribute (empty if decorative)
  • ▶Every form input has a <label> associated by for/id
  • ▶Buttons say what they do: "Add to cart" beats "Click here"
  • ▶Use real <button> elements, not <div onclick>
  • ▶Keyboard users can tab through every interactive element in logical order
  • ▶Color contrast ≥ 4.5:1 for normal text (WCAG AA)

ARIA — When HTML Is Not Enough

html
<!-- A custom dialog -->
<div role="dialog"
     aria-labelledby="dlgTitle"
     aria-describedby="dlgDesc"
     aria-modal="true">
  <h2 id="dlgTitle">Delete account?</h2>
  <p id="dlgDesc">This action cannot be undone.</p>
  <button>Cancel</button>
  <button aria-label="Confirm delete">Delete</button>
</div>

<!-- Live region (dynamic updates) -->
<div role="status" aria-live="polite">3 items in cart</div>

<!-- Hiding decorative icon from screen readers -->
<svg aria-hidden="true">…</svg>

Common HTML Mistakes The AI Will Catch

  • ▶Multiple <h1> tags on one page
  • ▶Using <b> instead of <strong>, or <i> instead of <em>
  • ▶Missing alt on images
  • ▶Using <table> for layout
  • ▶Inline styles instead of a stylesheet
  • ▶Omitting lang on <html>

Performance Checklist

  • ▶Use loading="lazy" for below-the-fold images
  • ▶Use decoding="async" to avoid blocking render
  • ▶Preload critical assets: <link rel="preload" as="font">
  • ▶Use WebP or AVIF instead of JPEG/PNG where possible
  • ▶Put <script defer> at the bottom of <body>
