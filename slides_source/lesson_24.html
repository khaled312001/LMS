Backup Strategy (3-2-1 Rule)

  • ▶3 copies of your data
  • ▶2 different media (disk + cloud)
  • ▶1 off-site copy
  • ▶Daily DB dump (mysqldump / mongodump) → encrypted → uploaded to Backblaze
  • ▶Monthly restore test — don't trust backups you haven't restored

Automated Backup Script

bash
#!/bin/bash
set -euo pipefail
DATE=$(date +%Y-%m-%d)
TMP=/tmp/shop-$DATE.sql.gz
mysqldump -u app -p"$DB_PW" shop | gzip > $TMP
# Upload to Backblaze B2
b2 upload-file --noProgress shop-backups $TMP db/$DATE.sql.gz
rm $TMP
# Keep last 30 days
b2 ls shop-backups db/ | head -n -30 | awk '{print $7}' | xargs -I{} b2 delete-file-version {}

Handling An Outage

  1. 1Post to status page: "Investigating"
  2. 2Check error tracker (Sentry) and server logs
  3. 3Roll back to last green release (if recent deploy)
  4. 4Mitigate (scale up, cache, rate-limit, disable feature flag)
  5. 5Communicate resolution
  6. 6Write a postmortem within 48h
