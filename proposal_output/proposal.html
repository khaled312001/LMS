أهداف المشروع

Project Objectives & Vision

إطلاق منصّة تعليمية جاهزة للاستخدام الفعليّ خلال 3–4 أسابيع (قابلة للنقصان)، قادرة على استقبال الطلاب وتقديم المحتوى التعليمي فور إطلاقها، مع بنية قابلة للتوسّع مستقبلاً.

3

أدوار رئيسية

6+

منصّات تسليم

2

لغتان مدعومتان

3-4

أسابيع للتسليم

تجربة موحّدة لكل الأدوار

دعم جميع أطراف العملية التعليمية (الطلاب، المدرسون، الإدارة) عبر نظام موحّد بصلاحيات منفصلة لكل دور.

تعليم مباشر ومسجّل

حصص مباشرة (فردية وجماعية) عبر Google Meet، إلى جانب مكتبة محتوى مسجّل بمشغّل محمي.

حماية المحتوى

حماية المحتوى من النسخ والتحميل عبر Signed URLs، Custom Video Player، وعلامة مائية ديناميكية.

ويب متجاوب مع قابلية التوسّع

منصّة ويب متجاوبة بالكامل (Responsive) تعمل على الجوال واللاب والتابلت، مع قابلية إضافة تطبيقات موبايل مستقبلاً.

بنية قابلة للتوسّع

تجهيز البنية التحتية بحيث يمكن إضافة ميزات ومراحل جديدة دون الحاجة لإعادة بناء النظام من الصفر.

إدارة ذكية بالبيانات

لوحات تحكّم مبنيّة على بيانات حيّة (إيرادات، تسجيلات، أداء الطلاب) لاتخاذ قرارات مدعومة بالأرقام.

الحصص المباشرة وحماية الفيديو

Live Classes + Video Protection System

يدعم النظام التعليم المباشر عبر نظامين متكاملين: نظام بثّ داخلي (Custom WebRTC)، وتكامل تلقائي مع Google Meet API؛ كبديل يمنح الأكاديمية مرونة كاملة.

نظام بثّ داخلي · Custom

  • نظام مبنيّ داخل المنصّة (WebRTC)
  • لا يحتاج أي برنامج خارجي
  • تحكّم كامل في التجربة
  • Whiteboard تفاعلي

تكامل Google Meet API

  • إنشاء اجتماعات تلقائيّاً
  • حفظ الرابط داخل النظام
  • حصص فردية (1-to-1)
  • حصص جماعية (Many-to-1)

نظام حماية الفيديو · DRM System

حماية متقدّمة للمحتوى المسجّل تمنع أي محاولة نسخ أو تسريب.

منع التحميل

منع تحميل الفيديو عبر أي أداة خارجية أو امتداد متصفّح.

تعطيل الزرّ الأيمن

تعطيل Right-Click واختصارات الحفظ و Dev Tools.

Signed URLs

روابط مؤقّتة لكل مستخدم، تنتهي صلاحيّتها تلقائيّاً.

علامة مائية

Watermark ديناميكي باسم الطالب و IP أثناء المشاهدة.

البنية التحتية للفيديو · Storage & Delivery

تخزين على Hostinger

مساحات تخزين آمنة ومشفّرة ضمن خوادم Hostinger المخصّصة للفيديو.

Bunny.net CDN

توزيع المحتوى عالميّاً مع سرعة بثّ عالية وجودة تكيُّفية.

Custom Player

مشغّل مخصّص يدمج كل طبقات الحماية في تجربة سلسة.

الاختبارات والشهادات

Exams System & Certificates

نظام الاختبارات · Exams System

نظام تقييم متكامل يدعم أنواعاً متعدّدة من الأسئلة وخصائص احترافية.

Multiple Choice

أسئلة اختيار من متعدّد مع خيارات غير محدودة وتصحيح تلقائي.

True / False

أسئلة صحّ أو خطأ، مثالية للتقييم السريع لفهم الأساسيات.

Essay · مقالي

أسئلة مقالية تتطلّب تصحيحاً يدويّاً من المعلّم مع تعليقات.

خصائص نظام الاختبارات

Timer · مؤقّت

تحديد وقت زمني والتسليم التلقائي عند انتهاء المدّة.

Attempts

تحديد عدد المحاولات المسموحة لكل طالب.

Random

ترتيب عشوائي للأسئلة والخيارات لمنع الغشّ.

Auto + Manual

تصحيح تلقائي للموضوعي ويدوي للمقالي.

نظام الشهادات · Certificates System

توليد تلقائي للشهادات الإلكترونية فور اجتياز شروط إتمام الدورة.

توليد PDF تلقائي

شهادة رسمية تُولَّد تلقائياً بصيغة PDF بمجرد اجتياز الطالب لشروط الإتمام.

  • اسم الطالب بالكامل
  • اسم الدورة والمدرّس
  • تاريخ الإتمام والمدّة الكلية
  • الدرجة النهائية والتقدير
  • توقيع وختم الأكاديمية الرسمي
  • رقم تسلسلي فريد للشهادة

QR Code للتحقّق

رمز تحقّق ذكي يسمح لأيّ جهة بالتأكّد من صحّة الشهادة في ثوانٍ.

  • رمز QR فريد لكل شهادة صادرة
  • صفحة تحقّق عامّة على الموقع
  • التأكّد بمسح سريع من الجوّال
  • حماية قويّة ضدّ التزوير
  • مشاركة مباشرة عبر LinkedIn

التقنيات والبنية التحتية

Technology Stack & Infrastructure

النظام بالكامل مبنيّ على Node.js و Next.js والتقنيات المرتبطة بهما، مما يضمن اتّساق البيئة ومرونة الصيانة وسرعة التطوير المستقبلي.

المكوّن · Component التقنية · Technology الوصف · Description
النظام الخلفي · Backend Node.js + Express / NestJS بيئة تشغيل JavaScript سريعة وقابلة للتوسّع تبني واجهة API موحّدة.
لوحة التحكّم · Admin Next.js + React واجهة إدارة سريعة وتفاعلية مع SSR وأداء متميّز.
موقع الواجهة · Landing Next.js + Tailwind موقع تعريفي سريع، متعدّد اللغات، محسّن SEO.
بوّابات الطالب والمعلّم Next.js + TypeScript بوّابات موحّدة ضمن نفس الـ Stack لتقليل التعقيد.
تجربة الموبايل Responsive Web (PWA) واجهة متجاوبة بالكامل + PWA قابلة للتثبيت، مع إمكانية عمل تطبيق أصلي مستقبلاً.
